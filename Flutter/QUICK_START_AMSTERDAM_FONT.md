# ⚡ Quick Start: Amsterdam Font (3 Steps)

## Step 1: Download Font (2 minutes)
```
1. Go to: https://www.dafont.com/amsterdam.font
2. Click "Download"
3. Extract the ZIP file
```

## Step 2: Copy Font File (1 minute)
```
Copy "Amsterdam.ttf" to:
/Users/s/Desktop/Business/Real estate/Proerty Flipper/Flutter/assets/fonts/

(Look for the PLACE_AMSTERDAM_FONT_HERE.txt file)
```

## Step 3: Rebuild App (2 minutes)
```bash
cd "/Users/s/Desktop/Business/Real estate/Proerty Flipper/Flutter"
flutter pub get
flutter clean
flutter run
```

## ✅ Done!

All headers in your app now use the Amsterdam font:
- Page titles
- Section headers
- Card titles  
- App bar titles

Body text still uses Poppins (Google Fonts).
